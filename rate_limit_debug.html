⚠️ Common Issues & Solutions:

  • Same localStorage: Browser tabs share localStorage. Use different browsers or incognito windows.
  • Cached tokens: Old authentication tokens might persist. Clear auth data and re-login.
  • Server cache: Backend is using local memory cache which is process-specific.
  • Session persistence: Make sure you're actually logging out and logging in as different users.
