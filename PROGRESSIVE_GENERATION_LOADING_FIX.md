# Progressive Generation Loading State Fix

## Problem Summary

When landing on the Pro Learning course page (e.g., `/pro-learning/course_xxx?topic=Topic&tab=reading`), there were two critical issues with progressive generation:

### Issue 1: Loading Indicator Not Showing
- **Problem**: The reading tab showed NO visual loading indicator (pulsing blue dot, "Loading..." text) while content was being generated
- **User Impact**: Users couldn't tell if content was loading or if the page was broken
- **Root Cause**: Race condition between manual `progressiveGenerationProgress` state updates and the generator's `onProgress` callback

### Issue 2: Content Not Rendering After Generation
- **Problem**: After the reading tab content was generated, the tab became enabled but content remained blank
- **User Impact**: Users saw an empty screen despite content being available
- **Root Causes**:
  1. Reading content was not properly sanitized in `onTabComplete` callback
  2. Loading states (`isLoading`, `progressiveGenerationProgress`) were not cleared when tab completed
  3. `isProgressiveGenerating` remained true after individual tab completion

## The Fixes

### Fix 1: Remove Race Condition in loadProgressiveTopicContent
**Location**: `ProLearningPage.jsx` line ~1840-1855

**Problem**: `loadProgressiveTopicContent` was manually setting `progressiveGenerationProgress`, which created a race condition with the generator's `onProgress` callback.

**Solution**: Removed manual progress state setting. Now the generator's `onProgress` callback is the single source of truth.

```jsx
// BEFORE (WRONG):
setIsProgressiveGenerating(true);
setProgressiveGenerationProgress({
  topic: topicName,
  tabType: 'reading',
  status: 'loading'
});

// AFTER (CORRECT):
// Let the generator's onProgress callback handle this
// No manual state setting to avoid race conditions
```

### Fix 2: Proper Content Sanitization in onTabComplete
**Location**: `ProLearningPage.jsx` line ~3267-3288

**Problem**: Reading content was set using raw `setSanitizedReading(String(freshContent.reading))` without proper sanitization, causing display issues.

**Solution**: Use `preSanitizeMarkdown()` to properly sanitize reading content before rendering.

```jsx
// BEFORE (WRONG):
setSanitizedReading(String(freshContent.reading || ''));

// AFTER (CORRECT):
const sanitized = preSanitizeMarkdown(freshContent.reading);
setSanitizedReading(sanitized);
setReadingRenderReady(true);
```

### Fix 3: Clear Loading States on Tab Completion
**Location**: `ProLearningPage.jsx` line ~3290-3302

**Problem**: After tab completion, `progressiveGenerationProgress` and `isLoading` states were not cleared, blocking content rendering.

**Solution**: Clear both states immediately when a tab completes.

```jsx
// NEW CODE ADDED:
// Clear progressiveGenerationProgress to remove loading indicator
setProgressiveGenerationProgress(prev => {
  if (prev?.topic === tabInfo.topic && prev?.tabType === tabInfo.tabType) {
    return {}; // Clear the state
  }
  return prev;
});

// Clear isLoading state to ensure content can render immediately
setIsLoading(false);
setLoadingStep('');
```

## How It Works Now

### 1. Initial Page Load
1. User lands on `/pro-learning/course_xxx?topic=Topic&tab=reading`
2. `selectedTopic` is set to the first topic (line 3196-3199)
3. Progressive generator starts running in background (line 3345)
4. `loadProgressiveTopicContent` is called for the first topic (line 3349)
5. Generator's `onProgress` callback fires and sets `progressiveGenerationProgress` with current topic/tab
6. **Loading indicator shows**: Pulsing blue dot and "Loading..." text appear on reading tab
7. Generator continues working...

### 2. Content Generation Complete
1. Reading content is generated by the generator
2. `onTabComplete` callback fires (line 3208)
3. Tab is added to `availableTabsForTopics` (line 3211)
4. Fresh content is retrieved and formatted (line 3233-3245)
5. Content is merged into state (line 3253-3263)
6. **Reading content is properly sanitized** (line 3267-3283)
7. **Loading states are cleared** (line 3290-3302)
8. **Content renders immediately**: Sanitized reading content appears on screen

### 3. Rendering Decision Logic
**Location**: `renderTabContent()` function (line ~4100-4180)

The content renders when ALL these conditions are met:
```jsx
const readingClientReadyForCurrentTopic = (
  activeTab === 'reading' &&
  contentTopicName === currentTopicName &&
  readingRenderReady && 
  sanitizedReading.trim().length > 0
);
```

Loading indicator shows when:
```jsx
// Desktop (line ~5850-5860)
isProgressiveGenerating &&
progressiveGenerationProgress.topic === selectedTopic?.name &&
progressiveGenerationProgress.tabType === tab.id

// Mobile (line ~192)
isDisabled && !isDisabledByTopic && isProgressiveGenerating &&
progressiveGenerationProgress?.topic === selectedTopic?.name &&
progressiveGenerationProgress?.tabType === tab.id
```
