Possible Issues & Solutions

Issue 1: Usage Stats Not Loading

Problem: usageStats is null/undefined
Check: Open browser DevTools → Console
Look for: Errors when fetching usage stats
Solution: Backend API might not be responding

Issue 2: Not in Pro Mode

Problem: Tooltip only shows when proMode = true
Check: Click "Create Course" button first
Look for: Button text should change to "Course Creation Mode"
Solution: Make sure you're authenticated and in Pro Mode

Issue 3: CSS Z-Index Problems

Problem: Tooltip hidden behind other elements
Check: Right-click → Inspect Element on button
Look for: z-index: 50 on tooltip container
Solution: Increase z-index or check parent containers

Issue 4: Backend API Connection

Check: Network tab in DevTools
Look for: POST requests to /api/ai/classify_topics/
Expected: 200 OK with usage_stats in response
If 404/500: Backend server might be down
